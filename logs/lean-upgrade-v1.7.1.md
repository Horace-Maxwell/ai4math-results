# v1.7.1: changes in `lean/`

v1.7.1 moves the Lean sources of v1.7.0 from Lean 4.33.1 / Mathlib v4.33.1 to Lean 4.34.1 / Mathlib v4.34.1.
Lean v4.34.1 fixes three soundness issues in the kernel and runtime (lean4 #15289, #15288, #15241; release notes:
https://lean-lang.org/doc/reference/latest/releases/v4.34.1/). No theorem, definition or statement was added,
removed or weakened.

## Lean sources (3 files, 13 lines)

In Mathlib v4.34.1 the ring argument of `PowerSeries.derivative` is implicit; in v4.33.1 it was explicit, so
`derivative ℤ A` no longer compiles. The same ring is now passed by name, as in `derivative (R := ℤ) A`. The
constant, the ring and the definition behind it are unchanged, so the statements mean the same (checked below).
The other 60 `.lean` files are byte-identical to v1.7.0.
